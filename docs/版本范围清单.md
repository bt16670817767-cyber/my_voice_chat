# SimpleVoiceChat 版本范围清单（MVP）

## 1. 版本目标
本版本仅交付可演示的语音聊天核心闭环，确保“连通 + 通话 + 状态可视”在受控环境下稳定运行。

## 2. 本版范围（In Scope / P0冻结）
1. 客户端可配置 Server IP / Port / Channel 并发起连接
2. 客户端可进行 Start Audio / Stop Audio 控制
3. 同频道双端基础语音收发可用
4. 客户端展示连接状态与音频状态
5. 服务端展示运行状态、端口与收发统计
6. 提供主链路与失败路径的基础验收清单

## 3. 本版不做（Out of Scope）
1. 商业化能力：账号体系、权限后台、计费系统、运营活动系统
2. 高级网络能力：复杂NAT穿透、多地域节点调度、QoS智能路由
3. 高级音频能力：回声消除调优面板、降噪策略编排、音效处理链配置
4. 数据平台能力：完整监控告警平台、长期指标看板、链路追踪平台化
5. 跨平台全面适配：仅保证当前已定义的 MVP 演示环境

## 4. 后续待办池（Backlog / P1）
1. 最近连接参数持久化
2. 自动重连机制与弱网提示
3. 质量指标展示（丢包/延迟估计）

## 5. 范围控制规则
1. 任何新增需求默认进入 Backlog，不直接插入 P0
2. 只有满足“影响主链路可演示”才允许升级为 P0
3. P0 变更需同步更新《MVP业务需求说明》和《演示验收清单》

## 6. 版本完成定义（DoD）
- 《MVP业务需求说明》已冻结并评审通过
- 《演示验收清单》执行通过，主链路和失败路径达标
- 本清单中的 Out of Scope 未被引入当前实现
