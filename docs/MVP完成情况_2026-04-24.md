## 2. P0完成项核对
1. **基础连接（已完成）**
   - 客户端支持 `Server IP / Port / Channel` 输入与 Connect。
   - 已补充连接中、连接成功、连接失败、断开后的状态反馈。
2. **音频控制（已完成）**
   - 支持 `Start Audio / Stop Audio`。
   - UI 中音频状态与录音流启动状态保持一致。
3. **基础通话（已完成，待人工验收）**
   - 服务端按频道转发音频数据，双端同频道可语音收发。
4. **运行可视（已完成）**
   - 客户端显示连接状态、音频状态、状态文案。
   - 服务端显示运行状态、端口、收发统计。
5. **失败路径基础能力（已完成）**
   - 服务端未启动/端口错误时，客户端可保持可理解的失败状态，不出现伪连接成功。
   - 重复 Start/Stop 在 UI 交互层避免状态错乱。
